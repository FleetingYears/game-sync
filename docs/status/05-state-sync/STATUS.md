# 计划 5：状态同步

状态：未开始；最后更新：2026-10-16。

## 目标

实现服务器权威模拟与客户端状态表现，并逐步加入预测和校正。

## 当前进度

尚未实现状态同步、服务器固定 Tick 或快照。

## 依赖与边界

计划 02、03 的玩法、协议和连接基础；若共享预测模拟则按需要使用计划 04。

网络接入遵循 [公共网络层实施计划](../03-shared-simulation/NETWORK_PLAN.md)。复用 UDP 传输、会话和房间基础；本方案定义输入确认、快照 Tick、基线/增量依赖、实体代次及快照通道的排序域，不将这些策略塞入公共传输层。增量缺失基线时需恢复，不能一律只收最新。

方案消息使用专属 .proto 定义并由 Protobuf 生成编解码，成熟库负责底层收发；首轮在 Windows 本地服务端和同 Wi-Fi 实际设备上验收。公网与 Linux 不作为当前依赖，协议优化以实际带宽/分配结果为依据。

## 表现适配与公共部分

复用 main 的公共 View，包括单位外观、血条、特效、音效、地图、相机与 UI；这些能力按计划 2 的实际完成情况使用，不视为已经全部实现。

StateSync 专属代码负责根据服务端快照、插值及本地预测校正计算显示状态，再调用公共 UnitView 等接口。快照缓冲、插值时间线、预测误差和校正策略不进入公共 View，也不依赖 FrameSync 的实现。
