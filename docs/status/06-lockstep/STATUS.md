# 计划 6：帧同步与回滚

状态：未开始；最后更新：2026-10-15。

## 目标

按逻辑帧同步输入，执行确定性模拟，并建立失步检测、回放以及按需预测回滚。

## 当前进度

尚无输入组帧、帧同步、回放或回滚。

## 依赖与边界

计划 03、04 必须具备可验证的协议与确定性模拟；复用计划 02 的表现。

## 表现适配与公共部分

复用 main 的公共 View，包括单位外观、血条、特效、音效、地图、相机与 UI；这些能力按计划 2 的实际完成情况使用，不视为已经全部实现。

FrameSync 专属代码负责从本地确定性模拟取得显示状态，衔接逻辑帧与渲染帧，并在回滚后修正外观。输入重放不能重复触发已播放的音效、特效等表现事件，具体事件标识与去重机制按回滚实现设计。网络帧、回滚历史和同步缓冲不进入公共 View，也不依赖 StateSync 的实现。
